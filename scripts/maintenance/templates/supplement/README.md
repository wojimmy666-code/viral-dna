# ViralDNA 补充迁移包

仅补充品类档案、Skill 封面/展示视频及选定模型密钥。适用于已完成账户整体迁移的正式服务器；不改手机号、密码、账户目录或项目，不覆盖 Skill 定义。

1. 将整个文件夹解压到 `C:\Projects\ViralDNA\.server\migration\` 下；不要仅复制 `payload.vdna-supplement`。
2. 把另外提供的 `.vdna-unlock` 文件保持原名，单独复制到 `C:\Projects\ViralDNA\.server\migration-secrets\`。不要与本包一起公开发送，也不要把它放入本文件夹或 Git。
3. 停止 ViralDNA 站点入口；运行 `.server\setup\05-run.bat` 选择 **4**，停止本项目服务。不要执行 `iisreset` 或停止其他站点。
4. 双击本文件夹的 `migrate.bat`，按 **1** 预览。确认账户 ID、待补品类数、展示素材和密钥名称。输出不显示密钥值。
5. 没有冲突时按 **2**，输入 `IMPORT` 执行。若有冲突，默认不导入；核对后可以按 **5** 切换为“保留正式端”，再按 **1** 重新预览、按 **2** 导入不冲突项。不会覆盖冲突内容。
6. 显示 `imported: true` 后，运行 `.server\setup\05-run.bat` 选 **3**，再恢复 ViralDNA 站点，登录验收。没有代码编译步骤，不需要重新初始化账户。

只迁移素材、不迁移密钥时，可以按 **6** 切换，然后重新按 **1** 预览。正式端已经有不同密钥时，会保留正式端并报告冲突，不自动替换。

若中断或断电，保持停服，再次运行菜单按 **3** 预览恢复、按 **4** 输入 `RECOVER`。不要删除数据目录中的迁移标记。若提示恢复冲突，停止操作并提供报告。

备份和恢复记录位于 `.server\data\supplement-migrations\`，运行报告位于 `.server\migration-reports\`。旧 `api.env` 的备份也使用该解锁文件加密，请把解锁文件保存在受控备份位置，不能丢失。

密钥只说明配置已搬入文件，不代表服务商余额、额度或密钥有效性已经验证。请在正式端后台分别检查模型配置。本机 Codex 登录、Cookie、OSS/DPAPI 凭据不在包内，需在正式端单独配置。

本工具不会更改域名、IIS、服务配置、Windows 账户、本机模型路径，也不会连接外部模型或 GitHub。
