# Homepage display fonts

Noto Sans SC, weights 600 and 800. Official Google Fonts text subsets downloaded on 2026-09-13; no external font requests are required at runtime.

- Source: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- Delivery: Google Fonts CSS2 text-subset API, `fonts.gstatic.com`.
- License and copyright: [OFL.txt](OFL.txt), obtained from the official Google Fonts family download manifest.
- Subset text: `ViralDNA看懂好视频，把创意做成片。有参考，就从分析开始想法Skill一段影像每步都由你决定将方法变为可复用的作让团队在同个项目里向前灵感不必停留脑海`

These are headline subsets, not complete Chinese body fonts. Other characters must retain a system CJK fallback; changes to display copy require regenerating the matching subset.
