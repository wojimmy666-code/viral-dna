# 首页三段视频接入 · 本地验收

日期：2026-09-13。用户明确要求将三个本地 MP4 应用到主页；本次未推送、未部署正式服务器。

## 结果

- 三段按 1 → 2 → 3 顺序拼接，总长 15.125 秒、363 帧、24fps、1280×720。
- 视频流直接复制，全部 363 帧解码后的 MD5 与原视频逐帧一致；未重编码、裁剪、放大或插帧。
- 仅首页派生版本移除音轨，MP4 元数据前置；原始下载文件保留。
- 首页真实静音循环播放，三个缩略图跳转同一影片对应位置，播放时间同步选中态。
- 首帧解码前保留真实视频封面；失败保留封面与重试入口。演示窗口完整展示真实视频和原生控制。
- 首屏媒体离屏、页面隐藏、菜单或演示打开时暂停；减少动态效果及节省流量默认不加载视频，可显式播放。
- 公开素材清单固定，不请求账户资产、项目、模型、编辑锁或私有 Skill 数据。

## 范围与限制

- 浏览器插件因本机运行时版本不兼容不可用，沿用已获准的项目隔离无头浏览器验收；只访问回环地址，使用临时独立配置，不读取个人浏览器资料。登录响应是合成测试，不代表真实账户 API 联调。
- 原视频是720p，本次不宣称1080p/4K；画面本身的生成质量与首尾构图差异保留，未做未经请求的重生或额外剪辑。
- 单支视频约13.56 MB，保持原码流；仅激活时加载，支持流式读取。正式站点的网络与CDN表现需部署后另行验证。
- 旧静态页面的像素匹配记录及独立 finish review 保留，不覆盖为本次新影片的机械门禁结果；本文件是本次接入的本地功能与视觉验收。
