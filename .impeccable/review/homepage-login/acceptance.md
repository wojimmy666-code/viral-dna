# 官网登录浮层：本地验收

日期：2026-09-13。范围是用户确认的官网登录浮层扩展，不是首页重设计或账号系统改造。验收时未提交 Git、推送 GitHub 或部署正式服务器；未使用真实账号密码。以下交付状态按验收时点记录，后续 Git 提交不代表已部署。

## 完成的行为

- `/` 与 `/login?returnTo=…` 保持同一个首页实例；所有官网创作入口打开深色原生登录弹层。直接打开、刷新、前进和后退均可用。
- 打开时暂停首屏影片，关闭恢复原有播放意图、页面滚动和触发控件焦点；保持手动暂停、减少动态效果及节省流量偏好。
- 支持关闭按钮、Escape、遮罩关闭、Tab 焦点约束、密码显示/隐藏；关闭清除表单密码，忽略已经放弃的请求结果。
- 沿用现有手机号/密码校验、真实认证 API 和站内回跳白名单；已有会话直接进入原目标，错误在表单中修正，连接失败可以重试，提交防重。
- 首页匿名浏览不调用私有工作台接口；仅打开登录才按需加载表单并检查认证状态。后台入口位于页脚，后台、初始化、激活和工作台内重新登录保持独立流程。
- 移动端按可见视口限制高度，表单可以内部滚动，关闭控件保持可达；根画布暗色与稳定滚动条预留只在打开期间生效，关闭恢复原属性。

主实现完成两轮批量检查：修正 Tab 约束和首页按钮样式继承；随后仅调整过严的整数像素断言并补齐截图，没有继续自行抛光。

独立评审初审提出两项 P2，集中修复后只对该清单复核：

1. 根画布预留滚动条区露白：临时从 `--home-ground` 取深色画布并设暗色浏览器控件，关闭完整恢复。截图及根属性/滚动恢复断言通过。
2. 登录按钮 hover 对比度不足：仅登录按钮使用 `#6355f6`，文字 `#f7f7f6`；浏览器计算值和独立计算一致，4.7083:1，默认状态为 5.1217:1。

[独立完成评审](finish-review.md) 最终为 `disposition: ship`，两项均为 resolved。该 verdict 只核对列出的两项修复，不冒充再次全表面评审。检测器运行一次；品牌 18px、弱提示 13px、内嵌圆角 6px、深色错误色四项 advisory 经评审接受为此次登录专用规范，不机械清零。

截图等待及测试清理也补齐：一次重拍后全部行为通过，但浏览器关闭早于拦截确认造成 CDP 收尾超时；另一次暴露导航取消请求的过期 ID。fixture 现停止接收、释放并等待在途确认，正常导航取消与关闭单独处理，其余拦截错误仍会使测试失败。最终 16/16 且进程正常退出；此过程没有再改 UI 或覆盖评审截图。
