## 4. 材料问题与优先级

**P2 / 问题 1：登录打开后，右侧出现贯穿全视口的浅白窄条。** 七张登录截图都可见约 10px 白色边缘，尤以 390×844 和 320×568 明显；`hero-repro.png` 同位置为深色滚动条。LoginDialog 打开时给 html 设置 `scrollbarGutter = "stable"` 并锁 body 滚动，landing 根规则只给滚动条配色，未覆盖隐藏后预留区的画布背景。白色边缘中断了本次明确要求的深色覆盖效果。修复应限定于公开 landing 的根画布/预留区，保留防止宽度跳动的稳定预留和关闭后的恢复逻辑。验收：同尺寸打开后整条边缘保持官网暗底，关闭无水平跳动或滚动位置回退，浅色独立账户页不受影响。

最终状态：resolved。七张修复后截图右侧均为连续深色画布。当前 LoginDialog 从 `--home-ground` 读取根背景，临时设置 `colorScheme = "dark"` 并保留 `scrollbarGutter = "stable"`；在打开前保存这三项内联属性，清理时逐项还原，同时恢复 body overflow。该实现范围与主代理报告的根背景、关闭属性恢复、滚动/焦点/视频及独立后台断言一致；没有扩大至工作台的永久主题变更。

**P2 / 问题 2：登录主按钮悬停时的 16px 文字对比度不足。** `login.css` 把登录主操作设为 16px，但它继承 `home.css` 的 `.vd-home .vd-primary:hover`：底色 `#7165ff`、字色 `#f7f7f6`，sRGB 对比度为 3.91:1，低于 craft-floor 的普通文字 4.5:1；默认底色 `#5b4df5` 为 5.12:1，符合要求。修复应仅给登录主操作提供仍为品牌紫、对比度至少 4.5:1 的 hover，并保留可见反馈；不改已批准首页的按钮世界或焦点圈。验收：核对实际 hover 的计算颜色和对比度，并确认正常、悬停、禁用状态依然可区分。

最终状态：resolved。仅 `.vd-home .vd-login .vd-login-submit:hover` 覆盖为 `#6355f6`；默认按钮与首页既有 hover 保持原值。主代理浏览器实测底色 `rgb(99, 85, 246)`、白字 `rgb(247, 247, 246)`，独立重算对比度 4.7083:1，超过 4.5:1。`login-hover.png` 与默认/服务失败截图显示悬停仍有品牌紫反馈，禁用状态仍可区分；没有牺牲字号、字色或状态文案。

四条检测器 advisory 不构成材料缺陷：18px 品牌用于紧凑标识行；13px 管理员说明层级清楚且对比充足；6px 眼睛控件圆角对应 8px 输入框内嵌 2px；`#ffc0c4` 为深色错误反馈且有明确文字，未仅依赖颜色。建议在登录专用规范中记录这些有意取值，不机械清零。
