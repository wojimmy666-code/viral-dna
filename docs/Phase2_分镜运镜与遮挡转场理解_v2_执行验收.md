# Phase 2：分镜运镜与遮挡转场理解 v2 执行验收

## 目标

修复仅依赖少量静态关键帧时，无法可靠识别连续推近、前景物靠近镜头、焦点变化和遮挡转场的问题。分析结果必须把当前分镜的有效内容与出场转场分开，并输出可直接用于视频生成的时序提示词。

## 已实现

1. 每个分镜继续保留 3 张基础关键帧，同时新增 6 张有效内容运动帧；存在出场转场时，再增加 3 张转场运动帧。
2. 为每个分镜生成独立的 H.264 分析片段。片段覆盖当前分镜有效内容；存在出场转场时延伸至下一场景稳定点。
3. 百炼 Qwen VLM 优先接收原生视频，并按片段时长自动选择 6、4 或 2 FPS。原生视频小于 2 秒或文件超过安全上限时，自动回退到带绝对时间标签的密集序列帧。
4. 新增结构化 `motion_phases`，分别记录相机运动、主体运动、前景运动、焦点变化、前景屏占比、遮挡比例、是否直接观察及置信度。
5. 新增结构化 `outgoing_transition`，支持硬切、叠化、前景遮挡、擦除、甩镜、匹配剪辑等类型，并记录遮罩对象、方向、末帧、连续性锚点和生成提示词。
6. 编译最终提示词时，把有效内容运动阶段与出场转场分别写入；连续镜头会消除“硬切”“画面切换为”等冲突说法。
7. 增加片段相对时间到原视频绝对时间的自动校正，防止后续分镜再次从 0 秒开始。
8. 分镜边界仍由程序候选与 VLM 共同确定；运动事实由连续视频 VLM 理解，二者物理隔离。

## 人工验收流程

1. 双击 `scripts/start.bat`，打开分析记录。
2. 进入上述记录，选择最新分析版本 `e6962a38...`。
3. 打开第一分镜，确认提示词包含稳定中景、手部入画、快速推近、丝带屏占比增至 100%、完全遮挡镜头和浅绿色模糊末帧。
4. 确认第一分镜提示词不再出现“切换到丝带特写”或“硬切结束”。
5. 打开第二分镜，确认时间从 `3.917s` 开始，且只描述户外稻田、少女与风吹丝带。
6. 新建创作方案时应基于这个最新分析版本；旧创作方案不会被自动覆盖。

## 后续方向

当前样例已证明 Qwen 3.7 Plus 的原生视频输入能够识别该类运镜，不需要立即更换模型。后续可在模型路由层增加另一款国内原生视频 VLM 做同片段 A/B 评测，指标包括时间边界误差、运动阶段召回、遮挡转场类型、末帧描述和单镜头成本。
