# Phase 2 · Batch 4.5.1 视频生成基础架构执行与验收

更新时间：2026-08-06

状态：开发完成，待人工验收

## 1. 本批目标

Batch 4.5.1 建立从“已审批分镜图片”到“可播放、可审核的视频候选”的完整基础架构。当前使用明确标注的零费用模拟 Provider，不调用真实视频生成模型。

模拟 Provider 会将已审批图片编码为无音频静态帧 MP4。它只验证任务调度、持久化、播放、下载、候选选择、审批、回退、重试和阶段门禁，不代表真实 Image-to-Video 效果。

## 2. 已完成范围

### 2.1 Provider 与生成任务

- 增加厂商无关的 `VideoGenerationAdapter` 协议。
- 增加统一 `VideoGenerationGateway`，负责输入快照、请求指纹、能力／费用快照、候选归档和质量报告。
- 增加 `simulated` 视频适配器，通过 FFmpeg 将已审批图片生成 H.264 MP4 和 WebP 缩略图。
- 每个分镜独立创建 GenerationRun；支持 1～4 个候选、排队、执行、取消、失败重试和服务重启恢复。
- 生成输入固定包含已审批图片、视频提示词、负面约束、时长、输出尺寸、Revision 和候选数量。
- 模拟任务费用为 0，UI 和快照均明确标记“非 AI”。

### 2.2 API 与状态机

- `POST /api/v1/production-shots/{shot_plan_id}/video-runs`
- `POST /api/v1/production-shots/{shot_plan_id}/video-approval/revoke`
- 复用候选选择、审批／退回、任务读取、取消和重试 API。
- 候选内容以 `video/mp4` 返回，缩略图以 `image/webp` 返回。
- 视频候选、Run、ApprovalEvent、Revision、费用和质量报告均写入工作区并可重复打开。
- 视频提示词修改只回退到 `shot_videos`，不会错误回退到图片阶段。
- 所有必需视频审批后才允许从 `shot_videos` 推进到 `editing`。
- 取消视频采用会恢复候选选择状态；若已进入剪辑／导出，必须明确确认下游失效。

### 2.3 前端工作台

- 工作流第 4 步“分段视频”在图片门禁通过后开放。
- 左侧显示有效分镜及各镜头视频状态。
- 主区并排显示已审批起始帧与视频候选；竖版和横版媒体均使用完整包含显示，不裁切主体。
- 支持原生播放／暂停／进度条、候选切换和 MP4 下载。
- 支持编辑并保存视频提示词、负面约束、时长和候选数量。
- 支持生成、取消、重试、选择候选、确认采用、退回和取消采用。
- 页面明确说明当前为静态帧模拟视频、无模型费用且无音频。

## 3. Batch 4.5.2 边界

下一批只接入第一套国内视频模型的 `remote_api`：

- GUI 和公共 API 不提供 `local_tool` 视频执行模式。
- 不实现本机 CLI 发现、自动配置、进程调用、沙箱、代理或费用预检。
- 仅在内部保留 Provider Adapter 协议，未来可以新增本机适配器而不改生产域状态机。

## 5. 人工验收流程

### 5.1 前置条件

1. 双击 `scripts` 目录下的启动 BAT，确认 API 和 Web 页面正常启动。
2. 打开一个已有创作方案；该方案至少有一个有效分镜。
3. 在“分镜图片”中确认所有必需分镜图片。

### 5.2 图片阶段门禁

1. 当仍有必需图片未确认时，确认“进入分段视频”按钮不可用，并显示剩余数量。
2. 全部确认后点击“进入分段视频”。
3. 确认步骤条第 4 步可点击，并自动进入“分段视频工作台”。

### 5.3 生成与媒体验收

1. 选择一个分镜，确认左侧起始帧与图片阶段已采用图片一致。
2. 编辑视频提示词，设置 2 个候选和一个合法时长，点击保存。
3. 点击“生成 2 个模拟候选”，确认页面显示排队／生成状态，完成后出现 2 个候选标签。
4. 播放两个候选，确认浏览器原生播放／暂停和进度条可用。
5. 对竖版图片确认画面完整显示，不被横向容器裁切。
6. 点击下载，确认得到可打开的 MP4 文件。

### 5.4 审核与回退验收

1. 选择候选 1，再点击“确认采用”，确认该分镜状态变为“已确认”。
2. 点击“取消采用”，确认恢复到待确认状态，可以改选候选 2 或重新生成。
3. 对另一个候选执行“退回”，输入原因，确认该候选不能再选择。
4. 修改已确认镜头的视频提示词时，确认系统提示现有结果会过期。
5. 关闭并重新打开页面，确认候选、已选状态、审批状态和视频文件仍可恢复。

### 5.5 全局门禁验收

1. 保留至少一个必需分镜未确认，确认“进入剪辑合成”不可用。
2. 确认全部必需分镜视频后，确认门禁显示“全部已确认”。
3. 点击“进入剪辑合成”，确认项目步骤推进到 `editing`，并显示后续 Batch 尚未开放的提示。
4. 返回分段视频并取消一个已采用视频，确认系统要求确认下游失效，确认后项目回退到 `shot_videos`。

## 6. 不在本批验收范围

- 真实人物动作、运镜或物理一致性。
- 视频模型 API Key、模型选择和真实计费。
- 本机 CLI／工具调用。
- 对白、TTS、声音克隆、口型同步或生成音频。
- 视频入点／出点、时间线剪辑和最终成片渲染。
