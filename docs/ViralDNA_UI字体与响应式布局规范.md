# ViralDNA UI 字体与响应式布局规范

版本：1.1
适用范围：ViralDNA Web 端全部工作区、分析报告、分析记录、资产与设置页面  
更新日期：2026-08-12

## 1. 目标

- 同一种信息角色在所有页面使用相同字号、字重、行高和颜色。
- 不通过缩小字体解决空间不足；空间不足时应重排、降列或换行。
- 正文和编辑器内容可长时间阅读，关键配置值完整可见。
- 支持浏览器 200% 缩放，不出现整页横向滚动、控件越界或关键文字截断。

## 2. 字体家族

产品界面统一使用一套本机系统无衬线字体，不加载远程字体：

```css
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"PingFang SC",
"Microsoft YaHei UI",
"Microsoft YaHei",
sans-serif
```

只有错误码、请求编号和技术诊断允许使用等宽字体。

## 3. 语义字阶

| 角色 | CSS 变量 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- | --- |
| Caption | `--type-caption-size` | `0.75rem` / 12px | 400 或 600 | 1.4 | 时间、ID、状态、模型批次、非关键元数据 |
| Label | `--type-label-size` | `0.875rem` / 14px | 600 | 1.4 | 字段标签、表头、按钮、导航子项、列表摘要 |
| Body | `--type-body-size` | `1rem` / 16px | 400 | 1.55 | 正文、说明、表单值、报告内容 |
| Editor | `--type-body-size` | `1rem` / 16px | 400 | 1.65 | 图片提示词、视频提示词、负面约束、长文本编辑 |
| Subheading | `--type-subheading-size` | `1.125rem` / 18px | 600 | 1.3 | 面板标题、卡片标题 |
| Heading | `--type-heading-size` | `1.25rem` / 20px | 700 | 1.3 | 工作区标题、主要分区标题 |
| Page | `--type-page-size` | `1.5rem` / 24px | 700 | 1.3 | 页面标题 |

约束：

- 系统 UI 不得使用低于 12px 的文字。
- 12px 只能承载非关键元数据，不能用于正文、表单值、按钮或提示词。
- 字重只使用 400、600、700；不得新增 650、750、800 等中间值。
- 产品 UI 使用固定 `rem` 字阶，不使用随视口连续变化的正文尺寸。

## 4. 文字颜色

| 角色 | 变量 | 用途 |
| --- | --- | --- |
| Primary | `--text-primary` | 标题、表单值、关键数据 |
| Secondary | `--text-secondary` | 正文、标签、次要说明 |
| Tertiary | `--text-tertiary` | 时间、ID、占位提示、非关键元数据 |

正文和占位文字都必须满足 WCAG 4.5:1 对比度。不得新增接近 `#999` 的浅灰正文。

## 5. 控件尺寸

| 角色 | 变量 | 高度 |
| --- | --- | --- |
| 默认控件 | `--control-height` | 44px |
| 紧凑控件 | `--control-height-compact` | 40px |
| 主要操作 | `--control-height-prominent` | 48px |

- 输入框和选择框内容使用 16px/400。
- 按钮使用 14px/600。
- 字段标签使用 14px/600。
- textarea 必须显式声明字体、字号、字重和行高，不得使用 `font: inherit` 继承标签粗体。

## 6. 提示词编辑器

图片提示词、视频提示词和负面约束统一使用 `prompt-editor-textarea`：

- 16px、400、1.65 行高。
- `max-width: 100%`，禁止产生水平滚动。
- 长文本使用正常换行和 `overflow-wrap: anywhere`。
- 宽屏阅读长度控制在约 70–90ch；窄屏占满可用宽度。
- 图片与视频工作台不得分别定义不同字重。

## 7. 截断策略

### 禁止截断

- 提示词和负面约束。
- 当前选中的模型名称。
- 输出尺寸、格式、字幕、费用和时长。
- 按钮文字、错误原因和操作建议。

### 允许截断

- 记录标题最多两行，详情页必须能查看完整内容。
- ID、哈希、技术请求编号可单行省略。
- 列表摘要最多两至三行。

关键数据不得使用 `white-space: nowrap` 与 `text-overflow: ellipsis` 的组合。

## 8. 响应式布局

- 容器查询必须绑定实际受约束的编辑面板，不能绑定包含左侧栏的外层工作区。
- 视频生成配置：宽屏四列、中屏两列、窄屏一列。
- 图片生成配置：使用 `auto-fit` 和不小于 15rem 的字段列。
- 输出摘要：自动从三列降为两列或一列，并允许值换行。
- 分析记录：中等宽度隐藏低优先级列；移动端切换为卡片，不通过缩小字号塞入表格。
- 操作区允许换行；窄屏主要按钮占满一行。

## 9. 页面映射

- 分析记录：表头与元数据 12px；记录标题和普通单元格 14px。
- 生命周期导航：项目 14px；数量 12px。
- 分镜事实卡：标签 14px；正文 16px。
- Prompt Package：分镜标题和摘要 14px；完整提示词 16px；时间和编号 12px。
- 图片/视频候选：当前候选标题 14px；模型、时间、质量和状态 12px。
- 导出摘要：标签 12px；值 16px。

### 9.1 分析报告五页一致性

“总览、爆款机制、分镜拆解、复刻与改进、提示词”共用同一套密度与字体角色，不为新增页签另建更大的展示型字号：

- 页签内容区统一使用 20px 内边距；移动端可收敛到 12px，但不得通过缩小正文换取空间。
- 页面内主要分区标题使用 Heading（20px）；卡片标题与关键结论使用 Body 或 Subheading（16–18px）。
- 解释、机制摘要、标签和操作说明使用 Label（14px）；时间、数量、置信度和模型信息使用 Caption（12px）。
- 视频事实、复刻建议和完整逐镜头提示词属于主要阅读内容，统一使用 Body（16px）；提示词采用 Editor 行高。
- 列表、详情和方案卡片优先使用 9–11px 圆角、14–16px 内边距和 8–12px 间距，不使用大面积展示型留白。
- 内容宽度由报告工作区决定，不在单独页签内设置额外的超宽 `max-width` 或居中画布。

## 10. 开发约束与检查

- 新代码使用语义变量，禁止新增 7–11px 的 `font-size`。
- 修改现有组件时，应移除对应旧字号，而不是在文件末尾增加宽泛覆盖。
- 禁止使用 `.workspace *`、`:is(small, button, label, ...)` 一次性覆盖所有元素。
- 回归测试应检查：提示词统一样式、配置区响应式列、关键值不使用 ellipsis。
- 人工验收尺寸：1280×720、1440×900、1920×1080，以及浏览器 125%、150%、200% 缩放。
