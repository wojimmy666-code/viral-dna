# ViralDNA UI 字体与响应式布局规范

版本：1.0

适用范围：ViralDNA Web 端全部页面、组件、弹窗和后续新增功能

更新日期：2026-08-20

完整且可执行的设计契约位于 [`apps/web/DESIGN.md`](../apps/web/DESIGN.md)。本文件保留为项目文档入口，具体实现以设计契约和 `apps/web/src/styles.css` 中的全局令牌为准。

## 核心规则

- 字号只使用 12 / 14 / 16 / 20px。
- 普通字重只使用 400 / 600。
- 普通文字只使用主文字与次文字两级灰度，禁用文字属于状态例外。
- 紫色只用于主操作、当前选中、焦点、链接和 `@` 素材引用。
- 成功、警告、错误和信息使用统一语义状态令牌。
- 提示词使用 14px、1.55 行高、10px 12px 内边距并占满编辑区可用宽度。
- 响应式通过改变布局结构完成，不通过缩小字体塞入内容。
- 新页面必须使用共享设计令牌及 `apps/web/src/ui/system` 基础组件。

## 验收尺寸

- 1440px：完整桌面布局。
- 1280px：主要双栏保持稳定。
- 1024px：受限工作区正确降为单栏。
- 768px：导航与表单结构适配平板。
- 390px：移动端无关键文字截断或整页横向滚动。
- 浏览器 125%、150%、200% 缩放下仍可完成主要任务。

## 开发检查

```powershell
npm run check:design
npm run test:web
npm run build:web
```

任何例外都必须在 `apps/web/DESIGN.md` 中说明原因和作用范围，不能仅通过页面末尾覆盖样式绕过规范。
