# 侧边栏展开／收起验收

## 本次变化

- 桌面侧边栏展开 232px、收起 72px；保留 ViralDNA 浅色和紫色视觉。
- 原视频项目 `/projects/:id` 和 Skill 项目 `/projects/:id/skill` 共用自动收起规则。首次进入、直接链接、刷新、切换项目或重新进入项目均收起。
- 同一项目中的步骤、分镜与后台刷新不重置手动展开状态。离开项目恢复普通页面的本机偏好，该偏好不会被项目内操作覆盖。
- 新建、项目列表、归档、回收站、Skill 广场、资产库、品类库、设置不触发项目自动收起。
- 图标栏保留所有导航，悬停或键盘聚焦显示名称；项目浮层提供当前项目、已归档和回收站。宽屏无悬停触屏另有“选择项目范围”按钮。
- 820px 及以下改用顶部菜单和导航抽屉。项目与资产等专注页面不再隐藏菜单入口；抽屉保留全部导航，支持 Escape、遮罩关闭、焦点循环与返回菜单按钮。
- 只改变外层布局，不按展开状态重建工作台；无需修改数据库或重启后端。

## 手工验收

1. 打开项目列表，点击品牌右侧收起按钮：正文增加 160px 可用宽度，导航变成图标栏。再展开，原入口完整显示。
2. 普通页面保持展开，进入任意原视频或 Skill 项目：自动变成图标栏；手动展开后切换项目内步骤，仍保持展开。
3. 返回项目列表：恢复进入前的展开状态。普通页面先收起再重复此流程：返回后仍收起。
4. 刷新项目、浏览器后退重新进入或切换其他项目：重新收起。刷新普通页面：保留本机选择。
5. 图标栏悬停“项目”：可直接点击三个生命周期入口；键盘聚焦项目后按右箭头可进入浮层，Tab 切换，Escape 返回项目按钮。
6. 手机宽度打开项目或资产库，确认顶部菜单可见。打开抽屉，检查全部导航；Escape 和点击遮罩均关闭，焦点回到菜单按钮。
7. 抽屉内从关闭按钮按 Shift+Tab 到最后入口，再按 Tab 回到关闭按钮；缩放回桌面再回手机时抽屉不应自行打开。
8. 打开提示词编辑器，反复收起／展开，确认文字、编辑器和当前步骤不重置。生成按钮不会被自动触发。
