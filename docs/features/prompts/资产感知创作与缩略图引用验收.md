# 资产感知创作与缩略图引用验收

> 现行功能说明 · 2026-09-09 整理。部署与首次使用见 [部署索引](../../deployment/README.md)；文中的历史验收记录保留原始时间和范围。

## 本次范围

首轮创作以品类库／品牌信息、创作方向和项目已选资产为依据，一次产生大纲、局部图片／视频提示词及图片引用。名称是主要匹配线索，目录和类型用于辅助消歧；这不是图像内容识别，不能把名称猜测当成产品事实。

模型只能选择传入的资产用途 ID，并明确返回原名称、用途和确定性。服务端再校验所选范围、名称歧义、授权、文件快照和素材用途。不确定、没有合适图片或名字仅为 IMG_001 等情况允许零绑定，不循环分配素材。文件变化、归档、删除或未授权的资产不参加自动匹配。

自动匹配只发生于首次创作及该次质量修复；不会因打开页面、刷新、编辑文字而重配用户已确认的引用。旧项目显示原绑定，不自动重新生成。

## 界面验收

1. 新建 Skill 项目，选择“滤芯正面”“生产线外景”等有意义名称的图片，并保留一个未选择的同品牌素材。生成大纲后，检查匹配镜头的正文、引用缩略图和资产绑定一致；未选择的素材不应出现。
2. 使用同名图片、含糊文件名或不相关素材，确认系统不会为了填满参考数量强行绑定。纯文字镜头可继续保存与生成。
3. 在大纲、分镜图片和分镜视频页面，提示词上方显示紧凑缩略图；正文只显示圆角标签“缩略图＋图片1”等编号，字体与正文一致。完整名称在预览、悬停和无障碍标签内保留，点击可定位、替换、移除。
4. 输入 `@`，仅显示项目已选素材。通过“添加资产”显式选择库中图片后，该素材加入项目并插入当前编辑位置；不需要填写资产 ID。
5. 删除最后一个引用标签后保存，检查实际生成绑定同步消失。撤销后提示词与绑定一起恢复。同一素材在正文出现多次时只提交一份媒体输入。
6. 测试中文输入、回车、粘贴、反向选择、Backspace／Delete、撤销／重做。尤其确认引用之后回车不会吞掉引用，视频提示词末尾空格不会在输入时被清除。
7. 保存后刷新，并在大纲、图片和视频阶段来回切换，核对稳定资产 ID 不变；全局提示词默认折叠，局部仍是默认编辑对象。
8. 一键生成前核对实际绑定；项目选择 20 个素材不等于每张图提交 20 个素材。实际模型数量、分辨率和身份能力限制仍在具体生成请求中校验。

## 引用预览与正文点击回归（2026-09-07）

- 大纲、分镜图片、分镜视频的复合编辑器不能包在原生 `label` 内。点击普通正文或空白处只定位光标，不会代替点击第一颗缩略图；已有预览关闭，不触发保存内容变更或生成。
- 鼠标悬停／键盘聚焦引用仍可预览，点击引用可定位、替换、移除。返回正文、点击关闭或按 Escape 后正常编辑；替换、移除及撤销仍同步保留文字和稳定引用 ID。
- 横图、方图、竖图完整显示在预览区，图片不能超过容器、覆盖名称或操作按钮。长名称可换行；图片加载失败保留占位和关闭操作。
- `npm run test:prompt-browser --workspace apps/web`：使用真实 Chrome／Chromium 运行 5 组行为回归，含 15 种图片比例与视口组合（1440／1024／390／320px 及模拟放大后的 800×450px 可用视口）。可通过 `CHROME_BIN` 指定测试浏览器；缺少浏览器时明确失败，不静默跳过。
- 浏览器回归只挂载内存中的真实编辑器组件，不访问项目接口或用户浏览器会话，结束后关闭浏览器并清理本次创建的临时测试目录。
- 本次前端常规测试 307 项通过，浏览器 5 组回归、设计规范检查和生产构建通过。业务修改仅涉及前端，未改动提示词、资产绑定和生成任务的后端逻辑。
- 本地实际页面另完成大纲／图片／视频三入口 × 1440／390px 核对：预览图片高度均被限制为 168px，名称在图片下方、无横向溢出；正文点击不打开预览且能关闭已固定预览。保存请求为 0，浏览器异常为 0，真实项目数据未改动。

## 分镜工作台精简与缩略图规则（2026-09-07）

1. 分镜图片列表不再显示时间段，原始时间数据仍保留给剪辑。
2. 有已采用图片时列表显示该图和绿色对勾；否则显示最新成功生成图和灰色空心圆。正在生成、失败或选择另一张预览，都不清空／替换已有采用图。无结果显示占位，不用参考资产冒充生成图。
3. “一键生成全部分镜图”只在点击后打开本次模型、分辨率、费用与数量弹窗。取消／Escape 不发送生成请求；确认时先补保存并预检，提交成功后关闭；错误留在弹窗内供修正。页面继续显示进度、结果、停止与继续操作。
4. 每次主动确认生成全部有效分镜，每镜固定 1 张；旧历史与采用结果不变。网络响应丢失后的重试复用同一个请求 ID 与冻结参数，不重复创建批次。
5. 单镜模型按钮紧凑显示 `image-2`，完整名称保留在悬停和模型列表，长名称不挤掉图标或箭头。选中资产不再展示参考角色下拉框，内部角色与身份检查不变。
6. 全局／局部提示词标题行共用组件。局部展开、全局收起；不再重复展示“分镜配置”或展开后的单类全局标题。
7. 系统编译与当前提示词视图清理连续中文句号，不在每次输入时改写。小数点、英文点号、省略号、引用标签和链接保留；只读投影不修改历史快照／候选。
8. 正文引用只显示缩略图与“图片1”等编号，继承正文的字体与字重，使用中性圆角细框。完整名称在预览中保留，点击、撤销、原子删除和输入法行为不变。
