# 账户存储、生成历史与服务器同步

> 现行功能说明 · 2026-09-09 整理。部署与首次使用见 [部署索引](../../deployment/README.md)；文中的历史验收记录保留原始时间和范围。

用户确认范围：个人默认 2 GB，企业默认 10 GB（1 GB = 1,000,000,000 字节），
企业成员共用额度，单 admin 手动调整容量。资产原件和生成历史共用内容去重账本。
缩略图及可重建缓存不计用户额度；移入回收站不释放容量。

服务端媒体、配额预留、同步断点与历史登记保存在账户工作区内的
`.viraldna/durable-storage.sqlite3`。长期原件位于 `objects/durable/`，
不位于项目可删除的目录，不按天过期。必须与账户数据库和工作区业务库一起备份。

本地连接器使用部署管理员配置的 `VIRAL_DNA_SYNC_SERVER_URL`（仅 HTTPS 源站，
不允许路径、账号、参数或重定向）。目标须运行兼容版本的 ViralDNA。
负责人登录目标账户后，必须明确确认目标账户，才允许开始传输。
密码只用于本次登录；同步使用单独的可撤销设备令牌，服务端只存令牌哈希，
Windows 连接器使用现有 DPAPI 密钥存储。令牌不能调用普通项目、资产或后台 API。
令牌 30 天失效，可由负责人重新连接；失效不会退出本地账户，不影响服务器已存文件。

手动开始同步后由本地 API 后台执行；关闭页面不停止，关闭电脑暂停，下次启动继续。
只同步当前账户登记的媒体与元信息，不扫描其他账户或任意电脑目录。
分块按断点写入，完整 SHA-256 校验后才登记成功；原有本地文件不删除。
目标账户资产采用稳定来源映射，不按名称合并，不覆盖远端人工修改。
每次最多两路、每块 4 MiB；失败后自动重试，也可再次点击同步立即重试。
分块断点 7 天无活动后释放，可从本地完整原件重传；此清理不删除长期原件。
更换目标需先断开并重新确认，同一目标保留断点，不同目标重置同步收据。

生成图片、视频的历史登记与“加入资产库”分离，未采用结果也保留。
相同内容在一个账户内只计一次；跨账户不做共享去重。
已经启动的生成任务优先保全结果，实际超过预留时标记超额并阻止新任务。
远端只对先前已预留的生成任务提供有界超额缓冲（最多 100 MB）。
若输出远超估算且服务器无法接收，完整结果仍在本地等待扩容后同步，不伪报云端保存成功。
原视频、用户上传音频、深度/清晰化结果及最终导出也纳入原件存储；低清预览和分析缓存不计。

首次启用会清点现有账户媒体；已有内容超出默认额度也不会删除。
清点在后台进行，期间可浏览，新的上传和生成等待清点完成。
接入真实目标服务器前需要确认服务器 HTTPS 地址、账户归属、持久化磁盘和独立备份。
不能把隔离测试中的模拟服务视为线上同步成功。

本期不提供在线付费、完整项目双向同步、自动项目冲突合并或自动清理生成历史。
