# 当前创作流程与生成规则

状态：现行规则，2026-09-09 按用户确认、工作台约束及当前账户／存储实现整理。本文用于纠正旧批次文档的入口、采用门槛和上游更新规则，不表示所有真实模型均已重新验收。

## 两条入口，一个后半程

- 分析入口：导入原视频 → 分析报告 → 创建创作方案。
- Skill 入口：选择 Skill → 品牌／产品与创作方向 → 选择相关资产 → 风格及大纲分镜。
- 两者共用：创作方案 → 分镜图片 → 分镜视频 → 视频剪辑 → 导出成片。

个人与企业是独立账户，没有空间切换；企业成员共享本企业项目及资产，一个项目同时只有一个编辑会话，其他成员只读。详见 [账户规则](accounts/account-system-implementation.md)。

## 分镜图片

- 项目创建时的图片／视频配置只是默认值，实际生成仍可在平台已启用且兼容的模型中选择参数，不被项目默认模型限制。
- 单镜生图默认 1 张，独立生成时可以选择多张；「一键生成全部分镜图」每个有效分镜固定 1 张，多画面分镜的手动整批处理主画面。
- 批量模型、分辨率、数量与费用确认只在点击批量按钮后展开；每次明确确认创建新批次。重试／继续未完成任务沿用原快照，不重复收费重做已完成项。
- 预览选择不等于采用。至少存在 1 张有效、实际已采用的分镜图才能进入分镜视频；0 张不能推进，不要求全部分镜或全部必需画面完成。
- 明确进入分镜视频时，后端持久化参与名单：纳入具有有效已采用图片的分镜，以及明确保留原视频的有效分镜，不按原始列表补入其余未采用分镜。仅采用 5 个分镜且没有额外保留项时，视频阶段对应这 5 个；同分镜多张采用图仍算一个分镜。原有未入选分镜和历史不删除，刷新不重算名单；返回图片页再次明确进入时才更新。历史尚无名单的项目在首次重新进入前保留原范围。
- 单画面时不展示冗余的时间段与画面轨道信息，多画面时保留排序和管理能力。已有新结果可用时，旧失败任务不应使分镜一直显示失败。

## 提示词与资产引用

- 图片、视频各自区分全局和局部提示词。准备、图片、视频阶段默认编辑局部，全局默认折叠；当前任务冻结完整提示词与版本，历史候选不被改写。
- 图片提示词只描述静态画面，不包含连续镜头、跨帧运动或时间连续性要求；视频提示词负责动作、运镜及时间变化。
- 首次创作只从当前项目已选资产中，主要依据名称匹配并绑定；类型和目录辅助消歧。不确定或没有合适资产时允许不绑定，不从整个资产库强行挑选。
- 编辑器引用显示缩略图与「图片1」等编号，使用稳定资产 ID 保存绑定；编号不是资产身份。`@` 搜索项目已选资产，新增库内资产通过用户明确的「添加资产」操作完成。
- 默认分镜参考图应在视频局部提示词编辑器中可见；编辑、自动保存和滚动不能造成引用菜单闪退或抢焦点。

详细记录：[全局与局部提示词](prompts/项目全局与局部提示词验收.md)、[资产感知与引用编辑器](prompts/资产感知创作与缩略图引用验收.md)。

## 分镜视频与剪辑

- 分镜标题保持简洁，支持调整顺序并选择是否参与下一阶段。
- 至少选择 1 个有效、已采用的视频参与剪辑即可进入下一阶段，不要求全部分镜完成。只勾选但没有可用已采用视频，不满足门槛。
- Skill 已有视频提示词时，不重复要求通过创作意图生成一遍提示词；配乐、旁白和字幕在后续剪辑／声音字幕阶段处理，不在创建时强制设置。
- 已有时间线不会因为读取页面、刷新或上游修改自动重建；明确选择「使用最新分镜」才生成新版本，保留旧版本和导出。

## 上游修改与必要校验

修改品牌、方向、提示词或上游内容后，只提示下游结果可能与当前输入不一致，不强制清空采用状态、重新生成或重建时间线。用户可以决定继续使用旧结果。

这不取消必要校验：缺失／不可读取媒体、账户权限、项目编辑锁、实际采用数量、模型能力、预算／容量等仍需通过。历史文档中因上游修改一律禁用后续步骤的规则已被替代。

## 历史与加入资产库

每张／段生成完成后独立登记历史，不依赖采用或加入资产库；再次生成与删除项目不自动清理长期历史。

加入资产库前可设置名称、目录等信息。切换候选时不显示查询中或已在资产库的状态按钮；只有确认当前候选确实不在库中，才显示「加入资产库」。候选状态按各自文件／来源判断，不能按分镜整体共用。

本地与服务器保存是不同状态：未连接目标或上传失败时，不能声称已保存到服务器。容量、同步、历史清理见 [同步与容量配置](../deployment/资产同步与容量配置.md)。
