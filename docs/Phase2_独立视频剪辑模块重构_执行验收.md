# Phase 2：独立视频剪辑模块重构执行与验收

更新时间：2026-08-11
状态：已实现，待人工验收

## 1. 目标与边界

本次重构把分段视频页面中的“剪辑准备”整体迁移到下一阶段“视频剪辑”。分段视频只负责生成、比较和确认视频候选；视频剪辑负责裁剪、质检、音频、字幕、转场、低清预览和后续导出衔接，封面由系统自动维护而不提供手动控制。

首期定位是轻量受控剪辑器，不复刻剪映或专业 NLE：

- 支持片段启停、排序、入点、出点和目标时长；
- 支持直接切换、淡入淡出和叠化；
- 支持 A1 源视频原音与 A2 附加音频的启停、音量和循环；
- 支持 T1 字幕逐条启停和文本修改；
- 支持基础技术质检、时间线版本、低清预览和最终导出；
- 暂不支持自由拖拽、多层视频、复杂特效、关键帧动画、曲线变速、音频波形精修或多人协作。

## 2. 新工作流

1. 在“分段视频”中为所有必需分镜确认采用一个视频候选。
2. 系统不再要求逐镜头执行剪辑准备，也不在该页显示裁剪和质检面板。
3. 点击“进入视频剪辑”后，首次访问时间线会按分镜顺序生成 `timeline.json`。
4. 用户在独立视频剪辑模块中调整片段、音轨、字幕和转场。
5. 草稿必须保存成新的时间线版本后，才能生成低清合成预览或进入最终导出。

## 3. 兼容迁移

时间线初始化采用两级策略：

- 新流程：直接读取已采用候选，使用候选完整时长、原分镜目标时长、中点封面和源音轨映射生成默认片段；没有质检结果时显示“待基础质检”提醒，但不阻止进入编辑器。
- 旧流程：如果存在与当前候选匹配且状态为 `ready` 的 `VideoClipPreparation`，优先迁移其裁剪、封面、音轨、字幕和质检结果。

旧 `PUT /production-shots/{shot_plan_id}/video-preparation` 与封面读取接口暂时保留，只用于旧工作区兼容；新 UI 不再调用它们。

## 4. 模块与领域设计

前端编辑器集中在：

```text
apps/web/src/video-editor/
├─ VideoEditorWorkspace.jsx
├─ editor-state.js
├─ video-editor.css
└─ index.js
```

分段视频工作台不依赖编辑器内部组件。生产工作流只通过 `VideoEditorWorkspace` 公共入口挂载模块，便于后续频繁替换布局、轨道和交互。

时间线继续使用不可变版本快照，并新增：

- 片段封面相对路径、封面时间、质检状态、质检报告、阻断项和提醒项；
- `TimelineBackgroundAudioTrack`，保存 A2 文件、名称、启用状态、音量与循环策略；
- 片段重新质检与封面提取操作，每次操作均创建新时间线版本。

## 5. 首期 UI

- 顶部工具栏：片段数、总时长、画幅、版本历史、保存、生成合成预览。
- 上方左侧：按方案画幅完整显示监看视频和固定播放控制条。
- 上方右侧：片段、音轨、字幕三个属性检查器。
- 下方全宽时间线：V1 视频、A1 原音、A2 附加音频、T1 字幕。
- 片段检查器：启停、排序、入点／出点、目标时长、声音策略、转场和质检摘要。
- 音轨检查器：A1 开关／音量／响度标准化；A2 上传或替换、开关、音量与循环。
- 字幕检查器：逐条开关与文本编辑。
- 1080px 以下监看区与检查器改为上下排列；媒体始终 `object-fit: contain`。

## 6. API

保留原时间线、版本、校验、预览和导出 API，并新增：

- `POST /api/v1/productions/{project_id}/timeline/clips/{clip_id}/inspect`
- `GET /api/v1/productions/{project_id}/timeline/clips/{clip_id}/cover`
- `POST /api/v1/productions/{project_id}/timeline/background-audio`
- `GET /api/v1/productions/{project_id}/timeline/background-audio`

上传附加音频支持 MP3、WAV、M4A、AAC、OGG 和 FLAC，单文件最大 100 MB。保存、质检和音频上传都携带当前 `revision_id`，避免覆盖其他版本。

## 7. 渲染规则

- V1 按顺序执行裁剪、变速、缩放补边和转场。
- A1 始终读取被分析的源视频音轨，不使用生成候选的原生声音。
- A2 可循环或截断到时间线时长，并与 A1 按各自音量混合。
- T1 根据片段相对时间重新计算全局位置，可输出浏览器字幕轨或参与最终烧录／内嵌。
- 低清预览和最终导出都只读取已保存的时间线版本。

## 8. 自动验证

- Web 组件测试覆盖阶段门禁、独立模块入口、V1/A1/A2/T1、裁剪、自动封面和质检。
- API 测试覆盖无旧准备记录的候选直达编辑、旧准备记录迁移、时间线版本、附加音频存储与修改。
- 真实 FFmpeg 测试覆盖 V1 视频、A1 原音、A2 附加音频、字幕和叠化合成。
- Vite 生产构建和 Impeccable 布局检测作为收尾门禁。

## 9. 人工验收流程

1. 打开一个仍在“分段视频”的创作方案，为所有必需分镜确认采用视频候选。
2. 确认分段视频页不再显示“剪辑准备”、入点／出点／封面／质检区域。
3. 不做任何额外准备，点击“进入视频剪辑”，确认可以正常进入。
4. 确认上方左侧为监看播放器、右侧为属性检查器，下方为全宽四轨时间线。
5. 确认轨道依次显示 V1 视频、A1 原音、A2 附加音频、T1 字幕。
6. 选择一个片段，修改入点、出点和目标时长并保存，确认版本号增加；封面由系统按时间线自动刷新，界面不显示手动封面控件。
7. 停用一个非唯一片段、调整顺序和转场，保存后刷新页面，确认设置保留。
8. 切换 A1 开关和音量；上传一段音乐到 A2，调整音量和循环并保存。
9. 编辑或停用一条字幕并保存，确认轨道摘要同步变化。
10. 点击“生成合成预览”，播放后确认画面比例完整、片段顺序、转场、A1/A2 混音与字幕符合设置。
11. 打开版本历史并恢复旧版本，确认系统创建新版本而不是覆盖历史。
12. 进入最终导出，确认导出继续绑定当前已保存时间线版本。

## 10. 后续扩展点

- 将检查器、轨道和监看器进一步拆成插件式面板；
- 增加音频波形、吸附、拆分、复制和批量节奏工具；
- 增加多层视频／贴纸／文本轨与关键帧；
- 将本地 FFmpeg 渲染器替换或扩展为任务队列／云端渲染器，而不修改时间线公共模型。
