原视频与替换资产驱动的新视频生成方案

01 · Goal

目标与边界

原始视频　＋　新人物资产　＋　服装／场景／产品／道具　→　新视频

白模、姿态提取、关键帧、遮罩和 Provider 托管身份映射都属于系统内部可能采用的中间过程。它们默认隐藏，仅在失败、低置信度、人工复核或用户主动进入高级详情时展示。

本稿不授权实施

  • 不修改数据库、Provider 适配器或模型能力目录。
  • 不重构当前分镜图片、分段视频和白模页面。
  • 不迁移历史方案或历史白模。
  • 后续必须另行形成并确认正式实施稿。

02 · User Experience

用户侧流程

用户提供

  • 原始视频。
  • 新人物资产。
  • 可选服装、场景、产品和道具。
  • 输出模型、画幅、清晰度、候选数和成本上限。

系统默认保留

  • 原视频动作。
  • 运镜、镜头时长与节奏。
  • 用户未要求替换的内容。
  • 原视频音轨进入后续剪辑阶段。

用户可见进度

  1. 分析原视频动作与镜头。
  2. 适配人物和其他替换资产。
  3. 准备视频生成素材。
  4. 生成分段视频。
  5. 检查人物与画面一致性。
  6. 合成新视频。

03 · Strategy

系统内部的候选执行策略

策略适用条件内部行为默认可见性
原视频直接参考允许原视频和新人物共同输入原视频提供动作和镜头，新资产提供身份与替换元素隐藏
托管人物 + 动作代理禁止原始真人身份素材托管资产提供身份，本机动作代理提供运动信息白模隐藏
视频重绘／姿态控制支持视频控制或重绘原视频作为控制视频，新资产作为替换目标控制方式隐藏
关键帧转视频仅支持图片、首帧或首尾帧先生成替换关键帧，再生成分段视频关键帧隐藏
不支持没有完整执行路径阻止付费任务并建议切换模型显示阻塞项

禁止静默降级：白模失败后不得上传原始真人素材；无法保留动作时不得静默改成普通文生视频；引用数量超限时不得静默丢弃核心资产。

复用原则

  • 更换人物、服装或场景时，动作代理通常可以复用。
  • 修改源视频范围或目标人物轨迹时，动作代理失效。
  • 切换到不需要代理的模型时保留历史，但不提交。
  • 修改中间资产产生新 Revision，不覆盖旧候选。

07 · Orchestration

自动编排

  1. 保存创作意图。
  2. 识别人物轨迹与分镜时间范围。
  3. 读取模型能力并解析替换资产。
  4. 建立执行计划并检查阻塞项。
  5. 按需生成或复用中间资产。
  6. 编译 Provider 提示词及素材顺序。
  7. 执行服务端安全与能力校验。
  8. 生成分段视频并检查一致性。
  9. 保留候选、成本和请求清单。
  10. 进入剪辑与合成。

08 · Prompt

提示词职责分离

用户只编辑创意描述。Provider Asset ID、图片序号、动作代理和本地路径由系统结构化编译。

目标人物资产：唯一人物身份来源。
原视频或动作代理：只提供动作、位置、镜头、节奏和时间结构。
服装资产：只提供服装款式、材质和颜色。
场景资产：只提供环境、空间、光线和背景。
限制：不得继承原视频人物未被要求保留的身份与外观特征。

09 · Advanced Details

中间过程默认隐藏，允许主动检查

主页面只保留“查看生成详情”的弱入口。高级详情可以展示执行策略、素材映射、关键帧、动作代理、实际提交清单、排除原因、技术提示词、质量报告和历史 Revision。

可查看

  • 图片和视频动作代理。
  • 替换后的关键帧。
  • Provider 请求素材清单。
  • 质量分与失效原因。

可调整

  • 源时间范围与人物轨迹。
  • 动作保留强度。
  • 重新生成和切换历史版本。
  • 恢复自动版本或删除闲置版本。

第一版不建议开放逐关键点骨骼编辑。

10 · Error Handling

失败处理

普通用户只看到可执行的业务信息，例如“需要关联当前模型可用的人物”“检测到多个人物”“动作解析置信度较低”或“当前模型不能同时完成指定替换和原动作保留”。

高级详情再显示 DWPose 错误、Provider 错误码、请求 ID、排除素材、质量分和完整请求清单。任何失败都不能绕过服务端安全门。

12 · Open Questions

尚未对齐的关键问题

  1. 是否要求尽量由一次 Provider 调用完成，还是允许内部多阶段生成。
  2. 核心目标是像素级、动作级、镜头级还是结构级复刻。
  3. Provider 托管演员是否只应作为 ViralDNA 人物资产的透明映射。
  4. 未提供服装或场景时应保留原内容，还是按人物／方案推导。
  5. 生成视频前是否需要确认替换关键帧。
  6. 自动选模优先质量、成本、速度还是动作还原度。
  7. 除白模外，是否允许深度、遮罩、骨骼和视频重绘作为中间表达。
  8. 模型不能完整保留动作时，是阻止、询问还是允许有提示地降级。
  9. 第一期是否允许同时替换多个人物。
  10. 中间过程的人工编辑应达到什么粒度。

处理原则：差异未对齐前只维护讨论记录；达成一致后另建“已确认实施方案”，不直接把本讨论稿改名为实施文档。
