# 统一创作工作台

两种项目共用 `创作方案 → 分镜图片 → 分镜视频 → 视频剪辑 → 导出成片` 五步导航、页头及后半程组件。

- 原视频项目保留分析报告入口，报告不嵌入 Skill 项目。
- Skill 的简报、风格、大纲与分镜放在“创作方案”下；原有八个后端阶段及人工批准不变。
- 两种项目的“视频剪辑”都有“画面剪辑 / 配乐与字幕”子导航，复用同一个时间线组件。Skill 仍分别确认画面及声音字幕。
- 参考资产和版本记录放在页头，不计入主步骤。Skill 在生产方案生成前可以查看创建时的参考素材。
- 无原视频时不显示保留原片段、源视频选段、沿用原音频及原视频深度提取入口。没有原图或已采用图片时，图片预览使用单列。
- 切换步骤、分镜、画面前刷新提示词及时间线的待保存修改；失败时留在当前编辑位置。后台轮询不替代人工批准。
- URL 和当前浏览器会话保存生产方案、阶段、分镜、画面及候选选择。模型、分辨率和音频生成策略不会因为此次界面调整而自动变更。

## 人工验收

1. 分别打开一个原视频项目和一个 Skill 项目，核对五个主步骤的文案、排版及参考资产/版本入口一致。
2. Skill 的“创作方案”内切换三个准备子步骤；未完成前序人工确认时，后续子步骤与生成区不可进入。不能以地址参数跳过确认。
3. 进入分镜图片、分镜视频，对比候选列表、编辑区、生成配置、采用操作；Skill 中不出现不可用的原视频入口。
4. 编辑提示词后立即切换分镜/步骤，再返回并刷新，核对已保存内容、阶段及选择。模拟保存失败后切换，核对错误提示及草稿未丢失。
5. 修改时间线入点/出点，立即切换到配乐字幕，核对自动保存；切换剪辑子页时保持同一时间线、撤销历史与播放位置。
6. Skill 完成画面确认后才能进入声音字幕确认，完成声音字幕确认后才能导出；原视频项目维持原有导出规则。
7. Skill 修改已确认时间线后，直接导出应提示重新确认，不能导出未经确认的新版本；成功导出后可以确认交付。
8. 观察进行中的生成任务：进度、心跳、逐张结果和消息中心仍正常；后台刷新不应跳到另一个步骤或分镜。
9. 在 1440、1280、1024、768、390px 宽度检查主导航、按钮换行、预览画幅和键盘焦点。

本轮还修复并加入回归保护：

- 切换分镜请求失败时不清空原预览；后台刷新不取消正在进行的分镜选择；过期请求报错不覆盖新选择。
