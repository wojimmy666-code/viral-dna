# 业务弹窗统一方案

日期：2026-09-26。

状态：共享组件、13 处原生业务调用迁移、现有业务窗口外壳收敛和规则门禁已实现。代码回归通过；浏览器视觉／键盘验收尚未完成：连接工具解析到 Node 20.17.0，要求至少 22.22.0，在连接浏览器前失败。未更改系统 Node、未重启正式本地服务、未部署或推送；未调用真实模型或操作项目数据。

## 目标与边界

用户点击生成、删除、改名等操作时，不再看到带有“127.0.0.1 显示”的浏览器消息框。业务确认、输入与费用提示使用同一套站内组件；已有站内确认和输入弹窗一起纳入。资产／风格选择器、构图编辑、空间参考等大型窗口保留功能和内容布局，只统一弹窗外壳与基础交互。

视觉与交互唯一规范为 [Web 设计契约](../../apps/web/DESIGN.md)，开发约束为 [前端 AGENTS.md](../../apps/web/AGENTS.md)，本文件仅记录现状、迁移顺序和验收计划，不维护第二套设计令牌。

不扩大为全站重设计；不把内联确认、Toast、抽屉和媒体预览一律变成居中弹窗。官网保留独立深色主题，浏览器文件选择／权限／刷新离开警告保留原机制。原视频与 Skill 共用工作台的入口必须一并验证。

## 截图场景的调整示意

窗口标题为“确认生成图片”，把对象、数量与费用风险分开呈现，按钮明确表示将发生的操作：

```text
确认生成图片                              ×

画面 1 · 生成 1 张候选
模型与尺寸：显示本次实际选择

费用暂不可估算
本机工具无法提供可验证的费用信息。
本次生成不代表免费。

                         [取消] [生成 1 张]
```

这里的模型与尺寸是待填充的真实数据要求，不是固定示例值。正文随实际画面、数量和费用来源变化；确认只授权本次展示的输入。取消不生成，连续点击只提交一次；受理失败在窗口中显示错误，受理成功关闭窗口并回到现有进度区。

## 实施顺序

1. 建立共享 `Dialog` 外壳与确认、输入、生成确认变体，统一可访问性、关闭策略、错误和忙碌状态。业务调用方持有草稿、提交逻辑、错误与请求 ID，组件不自行发请求或重试。先用隔离样例验证。
2. 优先迁移截图中的图片未知费用及视频费用确认；核对模型、数量、分辨率／时长等适用参数与实际提交一致。复用已有批量生成／缩放扩图的费用确认，不额外再叠一层通用确认。
3. 迁移其余 7 处原生确认和 4 处原生输入；保留归档、删除目录、项目永久删除等不同的数据后果，不能因统一文案而误称全部可恢复或全部删除素材。
4. 收敛现有站内确认与表单窗口，包括项目生命周期、资产移出／归档／入库、平台与账户操作；大型选择器和编辑器复用外壳，保留搜索、选择、引用用途、容量、版本冲突及草稿。官网、媒体和抽屉使用适用的主题／形态，不强套工作台窗口。
5. 将防回退检查接入 `check:design`，新增交互回归并进行桌面、窄屏与缩放验收；更新本文件实施状态及验收记录。没有完成的部分保持待实施标记。

## 必须保留的行为

- 浏览器消息框会阻塞当前交互，站内窗口不会阻塞后台轮询。不能只机械替换函数：窗口要固定目标稳定 ID 与输入，提交前重新检查账号、项目、编辑权、修订和生成参数，沿用草稿保存流程；条件变化时要求重新核对。
- 打开和取消不触发写操作或模型调用；费用确认不是自动采用，不能改变原图、候选、历史和人工采用状态。
- 失败保留草稿、已选资产及明确错误；提交中防重；网络结果未知时核验原请求，同一操作重试沿用幂等 ID，不盲目创建新的付费任务。受理成功不等于生成完成，取消窗口不等于停止后端任务。
- 最终危险动作展示准确范围与可恢复性，继续保留既有二次确认；不会为普通保存、选择、复制额外增加确认。已批准的候选区内联确认仍留在候选区。
- 一次只呈现一个主要模态决策；关联的舍弃／替换确认优先在原窗口内分步展示。会话恢复等例外要保留安全边界并专项测试。

## 验收与防回退

- 静态检查：禁止新增 `alert/confirm/prompt` 业务调用，包括裸调用、全局对象别名等绕过形式。过渡期按文件及具体调用逐项登记 13 处存量并只减不增，不能只按总数判断；迁移完成后清零。页面不得新建私有弹窗皮肤。
- 基础交互：取消、关闭、Escape 零写入；确认恰好一次请求；忙碌时不重复提交；成功关闭；失败保留草稿；取消和异常分别处理；切换目标或卸载不产生迟到写入。
- 业务回归：已知／未知费用、批量计数、不同生成入口、未保存草稿、归档与恢复差异、项目永久删除范围、编辑租约丢失、账号／项目切换、版本冲突、网络结果待核验及幂等重试。
- 可访问性与布局：可访问标题／说明／错误、初始焦点与归还、Tab 圈定、Enter 防误提交、中文输入法、滚动锁恢复、长名称／错误、1440／1280／1024／768／390px 与 200% 缩放；安全窗口与媒体／官网例外分别核验。
- 工程验证：实施 UI 后运行 `npm run check:design`、`npm run test:web`、`npm run build:web`，增加共享弹窗交互测试并记录实际结果；文档变更运行 `npm run check:docs`。浏览器验收使用隔离数据和模拟请求，不调用真实付费模型、不删除用户素材。
