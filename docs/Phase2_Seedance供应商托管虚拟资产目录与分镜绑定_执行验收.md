# Phase 2 · Seedance 托管演员与全场景深度绑定

更新时间：2026-08-17

## 目标

Seedance 路由将人物身份和空间控制彻底分离：

- 火山方舟托管演员是唯一人物身份来源。
- 项目人物、服装、场景、产品资产提供需要出现在成片中的外观。
- 本机全场景深度视频只提供动作、人物与物体位置、前后遮挡和镜头空间变化。
- 原始真人关键帧和原始人物视频不得提交给 Seedance。

## 分镜绑定

每个分镜最多启用一个 `role=actor_identity` 的托管演员绑定。绑定保存 Provider、ProjectName、Asset ID、名称和预览信息；提示词中不要求用户输入 Asset ID。

每个分镜可以保留多个深度历史版本，但生成时只允许一个通过质检且已启用的 `full_scene_depth_video`。切换演员不会改变深度版本，切换深度也不会改变演员身份。

## 请求编译

Seedance 请求编译器必须：

1. 将托管演员映射为 Provider 人物身份字段。
2. 将深度视频暂存为可访问的 HTTPS URL，并映射为空间控制参考。
3. 将场景、服装和产品资产按项目角色映射为外观参考。
4. 在自然语言指令中声明深度不提供身份、年龄、五官、服装、纹理、颜色、原场景光照、文字或水印。
5. 缺少托管演员、有效深度或公网媒体传输任一条件时阻止生成，不自动降级。

## 人工验收

1. 在模型与设置中配置火山方舟并同步托管演员目录。
2. 为分镜绑定一个托管演员，确认卡片显示名称和 Provider 来源。
3. 生成并启用一段全场景深度视频。
4. 打开“生成输入计划”，确认身份、外观、动作与空间三类来源分开列出。
5. 发起最低成本 Seedance 任务，检查请求媒体清单不含原始真人图／视频。
6. 更换托管演员后重新生成，确认动作空间保持、人物身份改变。
7. 更换深度版本后重新生成，确认人物身份保持、动作空间改变。

完整跨模型架构见 [全场景深度控制与资产重建](./Phase2_全场景深度控制与资产重建_执行验收.md)。
