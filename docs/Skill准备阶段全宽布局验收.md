# Skill 准备阶段全宽布局验收

## 本次范围

- 风格确认、大纲与分镜的内容区使用完整正文宽度。
- 保留现有导航、模型选择、候选采用、人工确认和自动保存逻辑。
- 不重试生成任务，也不处理模型返回镜头数量不符的问题。

## 布局规则

- 准备内容按容器宽度伸展，独立操作按钮保持内容尺寸；不影响剪辑、声音或导出工具栏。
- Look Test：容器不足 600px 单列，600px 起最多两列，1120px 起最多四列；未生成的候选不占空列。
- 预览按钮本身保持项目画幅，按窗口高度上限反算宽度；图片完整显示，不裁切、不放大空背景框。
- 大纲任务状态：900px 起横排状态、模型／心跳和操作，窄屏上下排列；进度与错误信息通栏展示。
- 已生成分镜：编辑器宽于 900px 时图片／视频提示词并排，否则上下排列；简短创作思路不额外扩展为说明面板。

## 已验收

- 两个实际页面：1920、1440、1280、1024、768、390、320px，均无横向溢出。
- 1280px 手动展开侧栏：候选从四列降为两列，内容重新分配宽度。
- 1920px：风格图区由 652px 增至正文全宽 1814px，四张竖版候选并排且比例保持 9:16。
- 生成失败状态使用通栏紧凑状态区；没有触发“继续生成”。
- 已生成分镜通过浏览器内隔离样例验收双栏、单栏和侧栏切换，不向真实工作区保存样例。
- 274 项前端测试、设计规范检查、生产构建通过。
- 布局检查采用独立结构审查与静态扫描并行，再通过真实页面截图核验；静态扫描无命中。

## 手工检查

1. 打开同一 Skill 项目的“风格确认”和“大纲与分镜”，确认正文左右边界一致。
2. 调整窗口宽度或展开／收起侧栏，确认候选列数、提示词列数随可用宽度变化。
3. 用 Tab 聚焦候选和操作按钮，确认焦点清楚、图片完整、按钮未拉长。

本次仅前端布局修改，刷新页面即可生效，无需重启后端。
