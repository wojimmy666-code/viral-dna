# 大纲与分镜简化验收

适用范围：Skill 项目的「创作方案 → 大纲与分镜」。原视频项目沿用现有流程。

## 页面

只保留简短的创作思路和每个分镜的图片、视频提示词。桌面双栏、手机单栏；直接编辑，不再切换编辑模式。导演大纲、连续性表、镜头参数、分数、锁定项、负面约束和全片规范不再作为独立界面出现。

分镜支持末尾添加、原位插入、删除和撤销。稳定标识随分镜保留，帧级时长在后台自动分配，总时长不变；撤销恢复原有时长权重，不会反复舍入导致节奏漂移。

## 保存与后续生成

- 停止输入 900 毫秒或失焦时自动保存。切换步骤和确认前，等待全部在途保存完成。
- 新增的空白分镜、临时清空的提示词、删除全部分镜均可保存为草稿。只有「确认并进入分镜图片」才校验完整性；后端再次验证，不能绕过人工门禁。
- 保存失败保留输入、显示重试状态并阻止内部切页。本地缓存保护刷新前未写入服务器的内容；服务器版本发生变化时，让用户明确选择本地草稿或服务器版本，不静默覆盖。
- 每次保存携带预期分镜版本。同一版本的并发提交只允许一个成功，不会覆盖另一个页面的修改。仅修改提示词不新建大纲版本。
- 全片共同约束和逐镜正文分别保存。实际生成使用合成后的完整提示词，Seed 和生产版本保留该快照；图片编辑不改写视频正文。
- 重新确认后同步到原生产项目，按稳定分镜标识更新。只修改视频提示词时保留图片采用状态；未改动镜头保留候选。删除只退出当前流程，不删除历史媒体或成片；恢复沿用原有镜头身份。
- 生成说明和模板枚举使用中文，保留品牌名、素材引用和专业术语。不会默默翻译用户手写正文。工业风、暖色调、摄影机和声音禁用规则来自对应 Skill，不再由通用编译器强加给所有 Skill。

## 人工检查

1. **先重启后端服务并刷新页面**：本次新增 `PUT /projects/{project_id}/storyboard-draft`，旧后端进程不会自动获得新接口。
2. 分别修改一个图片提示词和一个视频提示词，等待「已保存」，切页再返回，检查内容是否正确。
3. 插入一个空白分镜，确认它可以保存，但暂时不能进入图片生成；填写完整后再确认。
4. 删除中间分镜，点击撤销，检查内容和顺序恢复。
5. 已有后续产物的项目：修改一个镜头后重新确认，检查仍是原生产项目，未改镜头和历史候选仍存在。
6. 若需要真实生成验收，请由用户主动选定模型、分辨率及声音策略并发起任务；编辑与保存本身不会调用付费生成。
