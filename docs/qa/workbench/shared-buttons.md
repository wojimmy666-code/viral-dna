# 统一操作按钮验收

日期：2026-09-22。范围：本项目本地实现、模拟请求与隔离浏览器；未调用真实模型、修改真实账户数据、推送 GitHub 或部署服务器。

## 实现范围

- 新增共享 `Button` 与 `IconButton`，404 处普通操作入口接入，覆盖分析、复刻、提示词、制作、资产、平台连接、设置、成员与后台。沿用已有布局类，保留处理器、显式提交、引用、确认和计费流程。
- 按 [Web 设计契约](../../../apps/web/DESIGN.md) 使用紫色主操作、中性次操作、文字／弱化操作、红色描边中断操作及红色永久删除确认；尺寸、圆角、图标、焦点、禁用、加载、触控与减少动态效果状态集中实现。
- “停止任务”增加停止图标、稳定宽度的“正在停止…”状态与同步请求锁。请求失败后显示真实错误、允许恢复查询；等待或网络中断不冒充服务端已停止。
- 默认按钮不隐式提交；账户设置、企业名称、服务器验证、容量、服务器地址等原隐式提交入口改为显式 `type="submit"`。链接及下载仍为链接。
- 顶栏图标保持 44px，响应式显示隐藏由布局控制；提示词辅助操作保留已批准的 12px 弱化样式。官网、深色媒体、标签、导航、菜单和选择卡保留专用控件形态。
- 移除旧全局和平台页的重复按钮皮肤。`check:design` 增加静态防回退检查，检测普通原生裸按钮、缺失图标名称及遗漏提交类型；特殊无类名控件显式标注用途。

## 验证结果

- `npm run check:design`：14 项通过（包含新增的 6 项按钮契约测试）。
- `npm run test:web`：预检 85 项、主测试 333 项、后检 3 项通过。
- `npm run build:web`：通过，保留既有大 chunk 提醒；Sites 构建产物正常准备。
- `npm --workspace apps/web run test:buttons-browser`：通过。真实组件与生产 CSS，1440／1280／1024／768／390px 无横向溢出；桌面 36／40／44px、8px 圆角、14px 标签符合契约；手机按钮至少 44px，提示词辅助按钮仍为 12px。
- 隔离浏览器验证 Tab、Enter、焦点、图标可访问名称、原生表单提交、取消不提交、链接语义、禁用、加载宽度、防重复操作、取消失败恢复与后端确认后停止。减少动态效果关闭按钮转圈动画。Enter 验收发送完整按键文本，不把缺失字符的测试事件误报为界面故障。
- 账户浏览器 19 个子场景通过，包含顶栏窄屏、登录、成员创建／移除／恢复、后台改号、共享容量、回收站与草稿保护；沿用既有无头环境 Escape 的 DOM 回退验证限制。
- 创意浏览器场景通过：鼠标及键盘选择、单条修改意见、失败保留、同请求重试、展开拒绝与查询恢复，不增加付费提交。
- 桌面及手机状态展示截图保存在本机 `.impeccable/review/button-system/`，由测试重新生成，不作为真实客户或业务数据。

## 本地复核

1. 打开分析／创意任务，确认“停止任务”为红字细边按钮；单次点击后等待真实响应，不能反复提交。
2. 检查资产、设置、成员与后台表单，确认保存／取消、刷新／重试、删除确认层级一致，未改变原确认流程。
3. 缩小到手机宽度，检查按钮换行、44px 目标以及顶栏导航与搜索；用 Tab 检查焦点可见。

本轮未更改后端超时、生成策略、权限、存储或收费规则；部署与 GitHub 提交仍需用户另行指令。
