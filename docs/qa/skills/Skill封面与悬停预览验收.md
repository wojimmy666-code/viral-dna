# Skill 封面与悬停预览

> 验收记录：正文中的测试结果和界面描述对应当时批次，不表示本轮重新完成全部人工验收。当前流程及已替代规则见 [现行功能说明](../../features/README.md)。

## 使用入口

平台管理 → Skill 目录 → 对应 Skill 的“封面与预览”。图片、视频都可选；上传并处理完成后点击“保存封面”发布。取消不改变已发布封面；关闭后重开可恢复本机未保存设置。

- 图片：JPG / PNG / WebP 静态图，最大 20MB。
- 视频：MP4 / MOV / WebM，最大 200MB、120 秒。保留原件，自动提取第一可解码帧，并生成 H.264 MP4 静音预览。
- 有图时以图为封面；只有视频时使用首帧；均未设置时沿用旧封面。媒体加载失败逐级回退。
- 卡片维持 16:9；竖图、竖视频完整显示，不拉伸、不裁切主体。

## 交互验收

1. 上传图片和视频，观察真实文件上传进度与后台处理阶段；全部成功后方可保存。
2. 广场初次进入只请求封面；鼠标停留约 200ms 后静音循环预览，移开回到封面，再进入从头播放。
3. 连续预览两张卡片，同一时刻只有一个视频；离开可视区域或切换标签页停止播放并释放媒体。
4. 手机或系统“减少动态效果”下不悬停自动播放，可点击播放／停止按钮。
5. 移除视频只留下图片：保存后不再显示播放按钮；移除图片只留下视频：自动显示视频首帧；全部移除：恢复旧封面。
6. 文件错误、处理中断或网络失败时显示原因与重试入口，旧封面不变。服务重启后，中断的处理任务标为可重试，不伪装完成。
7. 两处管理界面同时编辑：后保存的旧版本会提示冲突，须重新加载，不能静默覆盖。

## 数据与权限

展示数据独立采用 `viraldna.skill-presentation/v1`，不写入 `viraldna.video-skill/v2` 的生成规则、内容摘要或历史项目快照。

保留 `items[]`、展示项 `id`、`sort_order`、`primary_item_id`；当前接口最多接受一个展示项，项内可同时包含图片与视频，未实现多图、多视频或轮播。客户端只提交素材 ID，视频首帧 ID 由服务端派生。

素材写入平台目录旁的 `platform-skill-media`，不依赖账户私有资产。仅管理员可以上传、读取未发布素材、重试与保存；公开内容请求必须验证素材仍属于已发布 Skill 的当前展示配置。移除绑定不物理删除原件。保存使用 `expected_revision` 做并发冲突校验。

主要接口：

- `GET/PUT /api/v1/admin/skills/{skill_id}/presentation`
- `POST /api/v1/admin/skills/{skill_id}/media`
- `GET /api/v1/admin/skill-media/{asset_id}`
- `POST /api/v1/admin/skill-media/{asset_id}/retry`
- `GET /api/v1/admin/skill-media/{asset_id}/content`
- `GET /api/v1/skill-media/{asset_id}/content`（仅当前已发布绑定，支持 Range）
