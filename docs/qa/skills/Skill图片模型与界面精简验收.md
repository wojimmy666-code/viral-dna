# Skill 图片模型与界面精简验收

> 验收记录：正文中的测试结果和界面描述对应当时批次，不表示本轮重新完成全部人工验收。当前流程及已替代规则见 [现行功能说明](../../features/README.md)。

## 已实现

- 风格确认删除目标摘要、风格与品牌标签、重复的 Look Test 标题；底层冻结风格约束继续参与生成。
- 大纲与分镜的视频提示词不再编入 `【剪辑落点】`。已有的这一结构化段落及系统固定剪辑文案被单独提取为剪辑建议，保留动作、运镜和结束状态。建议在视频剪辑中可编辑、自动保存，不自动修改入点或出点。
- Skill 创建向导可选择 `image-2（本机 ImageGen）`，复用原视频流程的本机工具路径、登录、适配器和输出恢复机制，没有新增 Images API。
- Look Test、单张分镜、分镜图片批量队列和全自动执行均遵循冻结的图片模型选择。本机调度模型单独记录，不作为图片模型名称显示。
- 图片、视频的分辨率选择与相关摘要使用 480p／720p／1080p／2K／4K 档位；实际请求仍使用像素尺寸。当前工具不支持的档位不提供，不静默降档。旧尺寸无法精确映射时显示“原有规格”。

## 页面验收

1. 打开已有 Skill 项目的风格确认页：只保留风格图及必要操作，原图片仍可正常显示。
2. 打开大纲与分镜：视频提示词不包含 `【剪辑落点】`，手写正文和结束状态仍保留。
3. 完成后续人工门禁进入视频剪辑，检查片段的“剪辑建议”；修改后切换片段、刷新，应保留修改，原入点、出点不应联动改变。清空建议后也应保持为空。
4. 从 Skill 广场新建项目，到“生成配置”主动选择 `image-2（本机 ImageGen）`。本机未配置时提供配置入口；不会自动改选本机或远程模型。
5. 选择图片分辨率，检查选项只包含当前模型实际支持的清晰度档位。例如本机当前能力上限为 2048 时，竖版不会提供 4K。
6. 选择视频模型后检查视频分辨率同样使用清晰度档位，提交时保留用户选择。

已创建项目继续遵循原冻结契约，不因系统默认模型改变而改用本机 ImageGen。

## 本机任务与费用验收

- Look Test 和批量生成复用已有并发设置，上限不超过 3；逐项完成后持久化候选并更新界面。
- 中断后优先核对已有输出。不确定是否完成的本机任务显示待恢复，不自动重新生成或切到远程 API。
- 未知图片费用不当成零。只有无硬预算的引导模式，在用户明确勾选费用确认后允许使用；全自动或硬预算模式要求可计价配置。
- 资产池可以包含多份素材，模型参考图数量限制在每张图片的实际生成请求处校验。

## 本次验证范围

- 前端自动化测试及生产构建通过。
- 后端图片、批量、Look Test、Skill 流程、种子快照、时间线回归通过，覆盖本机路由、并发、未知费用、错误模式／尺寸、中断恢复。
- 实际项目风格确认、大纲与分镜在 1600、1024、390 像素视口检查通过；创建向导已验证本机模型及清晰度选项。
