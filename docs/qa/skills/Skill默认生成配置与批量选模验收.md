# Skill 默认生成配置与批量选模验收

> 验收记录：正文中的测试结果和界面描述对应当时批次，不表示本轮重新完成全部人工验收。当前流程及已替代规则见 [现行功能说明](../../features/README.md)。

## 本次调整

- 创建页的图片模型、图片分辨率、视频模型、视频分辨率、视频帧率和生成新音频均标记为默认配置。
- 创建页不再设置配乐、旁白、字幕；新契约保存为未配置，在后续配乐与字幕阶段处理。原有项目和历史快照不迁移、不重写。
- Look Test、单张分镜图片、批量分镜图片使用平台完整图片模型目录，包括已有本机 image-2；本次选择不反写项目默认值。
- 视频模型、分辨率、候选数量、声音策略可以独立修改和保存；实际生成时仍执行模型能力、费用与预算校验。
- 批量入口选择模型和分辨率，显示画面数与预计费用，只保留“一键生成全部分镜图”。每次主动点击新建全量批次，不复用旧缓存，不覆盖历史和已采用结果。
- 运行中禁止重复提交；传输失败后重试同一任务快照；继续未完成任务不更换原参数。自动流程仍只补缺。本机未知结果先恢复输出，不盲目重新计费。
- 分辨率显示使用档位；历史非标准尺寸显示“原有规格”，不伪称标准档位。不兼容时提示重新选择，不自动降档。

## 人工验收

1. 从 Skill 广场创建项目，进入生成配置：检查“默认”标签，确认没有配乐、旁白和字幕字段。
2. 默认选择 Qwen，进入风格确认或分镜图片：仍可选择 Qwen Image 2.0、Qwen Image 2.0 Pro、image-2（本机 ImageGen）。未配置模型仍可见但不能提交。
3. 单个分镜切换图片模型并选择 720p：检查该分镜选择在切换分镜、返回和刷新后保留，其他分镜与批量选择不被改写。
4. 批量选择模型和分辨率后点击全量生成：检查任务记录实际模型、尺寸，进度和成功候选逐项更新；已有图片的画面也生成新候选，已采用图片不变。
5. 完成后再次点击：产生新批次和新候选。运行时不允许再提交；停止排队后的“继续未完成任务”保留原批次模型和尺寸。
6. 配置本机未知费用：未确认时不能提交；硬预算或全自动运行仍禁止未知费用，不得显示为免费。
7. 在分镜视频切换模型、分辨率和声音策略：保存后刷新保持本次选择；不支持的分辨率或音频策略阻止生成并提示修改。
8. 进入剪辑的配乐与字幕页再处理声音、字幕；不因创建页未配置而阻塞之前的风格、分镜、图片或视频阶段。
