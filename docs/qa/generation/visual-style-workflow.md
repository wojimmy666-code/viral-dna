# 管理员预设风格库

更新：2026-09-24。新风格库替代第一阶段的用户调参／账户预设表单；旧数据与接口保持兼容。风格是确定性的图片／视频提示词规则，不保证任意模型都能达到示意效果。

## 使用

1. “复刻与改进”及制作提示词工具栏点击“风格”，在弹窗按名称、标签或分类查找；支持我的收藏与最近使用。
2. 点击卡片后明确点击“使用此风格”，显示风格缩略图。取消不提交，更换／移除不触发模型。全局提示词内设置整片风格，单镜可覆盖或恢复继承。
3. 已展开的创意方案可修改制作风格；创建制作项目时带入。已经创建项目的方案直接编辑该项目的风格上下文，不另建项目。
4. 平台管理员进入 `/admin/styles`，维护名称、分类、标签、封面、最多四张示例、中文图片／视频规则与避免项。先保存草稿，再发布；停用后不再出现在新选择列表中。
5. 内置自然实拍、电影写实、商业棚拍、二维动漫、手绘水彩、三维卡通、旅行 Vlog 七种示意封面。示意图不是项目结果、生成参考图、模型选择或 LoRA。管理员可替换封面。

## 旅行 Vlog

- 在风格弹窗的“写实摄影”分类中选择“旅行 Vlog”，也可搜索“旅行”“vlog”或“日常随拍”。点击“使用此风格”后，对后续图片和视频生成生效。
- 风格依据用户认可的第二轮 D「日常随拍」提炼，沿用该图作示意封面。封面中的巴黎、铁塔、JK 服装、人物身份和天气不进入通用规则，也不作为参考图提交模型。
- 核心规则：环境主导、普通观察机位、人物与环境共用现场光和曝光、允许合理暗部、细节符合拍摄距离、避免广告精修和人景割裂。
- 没有明确景别、占比或机位要求时，全身环境镜头默认平视、人物占高约 45%–55%；已有特写、位置、构图与主体比例优先，不强制阴天、灰调、低饱和或固定地理场景。
- “1080p”仅描述普通视频的观看质感，不降低任务分辨率或质量。视频规则保留既定动作、镜头数量、时长和转场，不自动加晃动、慢动作或切镜。
- 内置 ID 为 `travel_vlog`，目录 ID 按现有规则稳定生成，图片和视频都可选择。新增种子可补入已有目录；管理员后续修改、停用、收藏、旧快照与旧素材均保留。
- 没有再次发起图片／视频生成，也未自动把任何现有方案切换到此风格。模型输出仍需验收，Codex 候选效果不等同于项目所有模型都能复现。

## 数据保护

- 平台目录独立保存在账户目录旁的 `visual-styles.sqlite3`，普通成员只能读取发布版本、维护自己的收藏／最近使用；管理员权限验证沿用平台认证。未发布／未绑定的上传图片只允许管理员读取。
- 风格 ID 与明确的发布版本一起保存。管理员保存草稿不影响已发布版本；发布产生新版本。旧项目与旧任务继续使用原快照，停用不删除历史版本。
- 图片／视频规则分别编译，图片规则去掉时序指令；风格只控制表现，不改变指定人物、服装、场景、构图、镜头数量和时长。
- 历史创意输入 `visual_style_snapshot` 保持不变；未创建项目的展开方案另存 `production_visual_style_snapshot` 与修订号。已创建项目使用现有全局提示词修订机制，保留手写正文与单镜覆盖。
- 入队任务冻结本次有效规则，单图、批次、视频与多镜视频继续使用同一编译链路。封面 URL 不进入模型参考图列表；旧候选、采用状态、时间线与费用不改写。
- 版本冲突不自动重发写请求。读取最新版本后保留弹窗中的待选风格，由用户核对并再次应用。读取失败结束等待状态，仍允许切换历史；依赖未读取风格的发布操作保持禁用。
- 管理员草稿、风格保存失败与冲突不伪报成功；后台导航与账户导航检查未保存修改。

## 验证与边界

- 后端 `test_style_library.py` 与 `test_visual_styles.py`：草稿／版本／停用、素材访问、上传校验、管理员权限、成员隔离、制作风格修改与发布、SQLite 重启、单镜覆盖、历史批次、多镜视频、旧客户端兼容。
- 旅行 Vlog 回归额外覆盖新旧目录增量初始化、D 封面读取、分类标签与图片／视频选择、示例内容不泄漏到规则、明确构图优先、图片规则不混入动态指令。
- 前端 `visual-style.test.mjs`：实际事件处理器的延迟／过期响应、版本冲突后的显式重试、失败结束等待、搜索分类收藏过滤、手写正文保护、继承、创意参数与 TXT 导出。
- 相关项目提示词、创意、视频组与账户隔离用例同时回归；前端完整测试、设计契约检查、构建需通过。
- 示意封面由内置 imagegen 生成；原始提示词及来源记录在 `services/api/src/viral_dna_api/style_previews/README.md`。没有启动用户项目的真实付费生成或质量评审任务。
- 首批风格库验收时，Chrome 扩展可被发现，但控制调用超时；当时没有最终 1440px／390px 截图结论，构建和源码复核不能替代浏览器视觉验收。待连接恢复后验收弹窗滚动、焦点返回、Escape、触屏目标、封面加载及无横向溢出，不重复提交实际生成。
- 首批风格库交付未自动重启服务，新后端接口须更新／重启服务后生效；未推送 GitHub。
