# 提示词来源与中文校正验收

日期：2026-09-21。范围：本地代码、临时数据库与模拟模型。不调用真实付费模型，不直接改写用户现有英文方案，不部署正式服务器。

## 行为

1. 分析报告的提示词页增加“原片提示词 / 方案提示词”。原片仍是原分析；方案选择器显示具体名称与来源。多个方案时要求显式选择，不猜测最新批次。
2. 在复刻与改进点击“查看方案提示词”，进入该方案的文档；已创建项目直接读取制作中的最新内容，未创建方案只读预览。URL 保留来源和报告页签，刷新、返回不依据批次时间改选。
3. 方案文档按活动分镜显示全部画面，以及最新 `ShotVideoGenerationDraft` 的视频正文、负面约束；没有草稿才读取分镜初值。全局默认折叠；桌面两栏、手机单栏。
4. 已创建方案支持自动保存，与分镜图片/视频阶段共用数据。资产引用保持原子标签，需改变引用时前往对应分镜编辑器。复制、TXT 下载跟随当前文档；原片沿用结构化编辑。
5. 新创意提示词明确要求中文，在完成与发布前检查语言；不合格结果标为失败并保留可校正正文。允许 JK、AI、HDR 等专业缩写、中文正文中的品牌名以及有明确标注的英文台词/标识。不会自动重试收费模型。
6. 旧英文结果点击“转为中文”，展示当前模型与预估费用；确认后只生成语言修订预览。原提示词暂不改变，预览可展开对照原文，用户再确认应用。未创建的方案可从中文预览确认创建制作项目。

## 数据与并发

- 文档是实时投影，不新增独立提示词副本库。保存同一事务更新分镜、全局修订、最新视频草稿、生产版本及已应用标记。
- 比较文档指纹与生产版本、全局版本、所有视频草稿版本。冲突返回 409，不部分写入正文；前端保留输入并阻止来源切换。仅局部变化时不增加无关全局版本。
- 提示词编辑不增删、重排镜头或画面。中文修订检查 ID、顺序、约束条数、数字参数、资产引用不变；已有中文和空字段不能改写。已有采用结果、生成配置、输入计划、素材指针及历史保留。
- 中文预览重新验证补充想法的引文证据，不能继续沿用翻译前的失效引文。语义等价仍需人工预览确认，自动检查不能证明每个翻译细节完全准确。
- 中文校正复用持久化创意任务、模型费用账本、240 秒超时、取消、启动恢复和请求幂等。低温度 0.1；只调用确认的当前模型，无隐藏回退。GET 不调用模型；确认应用不再次调用模型。
- 原始分析不改写；原始创意、Seed 与历史版本仍保留。新接口沿用账户工作区隔离、CSRF 和项目编辑租约，不新增跨账户访问能力。

## 用户现有案例

《世界地标里的格纹呼吸》原有 5 镜英文方案不自动重写。打开提示词页，选择该制作方案，点击“转为中文”，确认费用并审核预览后应用。原片 9 镜仍可在“原片提示词”查看。
