# Phase 2 Batch 4.3：分镜编排与提示词资产关联验收

## 目标

Batch 4.3 将“分镜图片”从逐条固定审批改为可编辑的分镜编排工作台：用户可以舍弃、恢复、新增和调整分镜顺序，直接在原始关键帧与 AI 生成图之间选择最终画面，并在图片提示词中通过 `@资产` 绑定人物、产品、服装或场景参考图。

## 已实现范围

### 1. 分镜生命周期

- 分镜新增 `active` 与 `discarded` 两种生命周期状态。
- 舍弃采用软状态，不删除关键帧、生成任务、候选图、审批记录或费用信息。
- 已舍弃分镜不参与图片阶段 Gate，也不能继续修改、选帧、生成或审批。
- 创作方案至少保留一个有效分镜。
- 已舍弃分镜可以恢复，恢复后默认追加到有效分镜末尾。

### 2. 新增分镜

支持三种方式：

- 复制当前分镜：复制提示词、约束、关键帧和参考资产绑定，不复制生成结果与审批状态。
- 从源视频选段：指定开始、结束和关键帧时间，服务端从源视频提取关键帧。
- 空白分镜：创建默认 3 秒的无关键帧分镜，前端自动切换到纯文生图模式。

### 3. 分镜排序

- 有效分镜支持拖拽排序。
- 同时提供上移和下移按钮，支持鼠标之外的明确操作方式。
- 排序仅修改展示和后续合成顺序，不使已生成图片或已审批结果过期。
- 分镜 UUID 保持不变，`index` 在一次版本事务中重新编号。

### 4. 图片选择工作台

- 移除下方重复的候选卡片区域。
- 左侧显示源关键帧，右侧显示当前 AI 候选图。
- 候选多于一张时，可在右侧画面标题中切换候选。
- 点击两张大图即可选择，统一通过“采用所选画面”确认。
- 仍保留“从视频重选”和“退回修改”能力。

### 5. 参考资产与 `@` 关联

- 参考资产绑定列表显示真实缩略图、资产名称和类型。
- 在图片提示词输入 `@` 会打开资产选择菜单。
- 选择资产后同时完成：
  - 向提示词插入 `@资产名称`；
  - 保存稳定的参考资产 UUID；
  - 自动补齐参考资产绑定和默认角色；
  - 将结构化关联写入图片生成输入快照。
- 资产名称只作为可读标签，实际关联依赖 UUID，后续改名不会破坏引用关系。

## 数据结构

`ShotPlan` 新增字段：

- `lifecycle_status`：`active | discarded`
- `source_kind`：`analysis | duplicate | video_range | blank`
- `image_prompt_mentions`：由 `reference_asset_id` 与 `label` 组成的结构化列表

创作方案详情新增 `discarded_shot_count`，原 `shot_count` 仅统计有效分镜。

## API

- `POST /api/v1/productions/{project_id}/shots`：新增分镜
- `PUT /api/v1/productions/{project_id}/shots/order`：调整有效分镜顺序
- `POST /api/v1/production-shots/{shot_plan_id}/discard`：舍弃分镜
- `POST /api/v1/production-shots/{shot_plan_id}/restore`：恢复分镜
- `PATCH /api/v1/production-shots/{shot_plan_id}`：支持保存 `image_prompt_mentions`

所有写操作继续使用 `expected_revision_id` 做乐观并发控制，并生成不可变版本快照。
