# ViralDNA Product Context

## Register

Product application.

## Platform

Desktop-first web application.

## Users

Short-video creators and operators who spend long sessions analyzing source videos, managing reference assets, generating candidates, reviewing results, and preparing final edits.

## Product purpose

Turn source-video evidence into a controlled production workflow that connects analysis, prompts, generation candidates, editing, and export. Success means fewer manual transfers, transparent cost and task state, and recoverable production artifacts.

## Positioning

An evidence-driven video reproduction workbench that keeps identity, assets, generation, review, and export in one auditable workflow.

## Brand personality

Calm, precise, and dependable.

## Anti-references

The product is not a decorative AI dashboard. Avoid excessive cards, gradients, many competing gray levels, hidden irreversible automation, and implementation details in the primary task flow.

## Design principles

- Put user decisions before implementation detail.
- Require an explicit choice before expensive or irreversible work.
- Keep long-running tasks durable, observable, cancellable, and recoverable.
- Distinguish source inputs, reference assets, candidates, and output versions clearly.
- Use progressive disclosure so advanced controls do not overwhelm the main workflow.
- Preserve originals when deriving enhanced or edited output versions.

## Accessibility and inclusion

Maintain readable contrast, keyboard access, visible focus states, reduced-motion support, and status communication that never depends on color alone.
